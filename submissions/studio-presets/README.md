# Studio Presets 1.0.0

Declarative clock and RAM widget presets for the Studio library. No scripts,
network access, processes or new permissions. Installing only adds library
choices; users must add a widget to a draft and explicitly deploy it to Core.
The RAM widget requires the existing supported native widget integration.
